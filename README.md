# TACTA

TACTA card-placement prototype.

This project currently contains:

- the official rulebook in `rules/TACTA_RULES.pdf`
- reference crops from the rulebook in `reference/cards/`
- a local browser prototype for testing card placement against the starting card

## Run locally

Start a static server in this folder:

```sh
python3 -m http.server 5173
```

Then open:

```text
http://localhost:5173/index.html
```
